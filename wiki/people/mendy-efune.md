# Mendy Efune

Builder of **ChatTorah.com** and **ChabadUp.com**. Champion of
**[[../tools/claude]] Code** as a Lovable / Elementor / WordPress
alternative.

## Things he's built

- **ChatTorah.com** — AI for Torah, in development since 2025-08:
  *"BezH we're working on developing a solution for this:
  ChatTorah.com"* [chat 2025-08-06]. Anticipated as a Torah-hallucination
  solution. App at `app.chattorah.com` (coming soon as of [chat 2026-04]).
- **ChabadUp.com** — networking platform for shluchim and the broader
  Chabad community, built *"100% with AI."* [chat 2026-01-06]

## Editorial positions

> *"If you build using Claude Code you simply ask it how it can improve
> the security … because you have banking info … what would it
> suggest?"*
> — [chat 2026-01-11], defending vibe-coding against security
> concerns.

> *"AI is ultimately limited by human imagination. Precision, judgment,
> and nuanced customization will always require people."*
> — [chat 2026-02-15], in the "do we need to learn AI?" debate.

> *"Make.com is basically a thing of the past now. Claude Code…"*
> — [chat 2026-02-22], on automation platform obsolescence.

> *"Claude Design is pretty promising, although I have not quite figured
> it out yet."*
> — [chat 2026-05-13]

## Areas of expertise

- **Claude Code as serious app builder** — promoted as cheaper and
  more flexible than [[../tools/lovable]] / WordPress / Elementor.
  [chat 2026-01-08, 2026-01-13]
- **AI-built web platforms** at full-app scale (ChabadUp).
- **HTML form generation via Claude** — Mendy Efune is the canonical
  voice for *"don't use JotForm/Typeform, have Claude generate a form
  that connects to Google Sheets / email directly."*
  [chat 2026-03-16]
- **Security thinking** — repeatedly asserts that AI-built apps can be
  *asked* about security improvements, not blindly trusted.
