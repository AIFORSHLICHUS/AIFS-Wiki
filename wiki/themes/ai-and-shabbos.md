# AI and Shabbos

The halachic edge case the chat keeps returning to: **can an AI agent
run while a shliach is shomer Shabbos?** Different from
[[ai-and-torah-accuracy]] (about AI *content* fidelity); this is about
AI *labor* during sacred time.

## The framing question

[chat 2026-04-27, +39 340 359 5009]:

> *"Is it permissible for Claude to work on Shabbos on your computer?"*

This is not idle theorizing. Real cases that triggered it:

- **Claude Dispatch / Cowork** running CRM data entry overnight.
- **Manus.im / Nanoclaw** agents executing multi-step tasks.
- **Lovable / Replit** apps deployed at edge runtimes that hum on
  Shabbos.
- **Scheduled email sends** generated by AI.
- **WhatsApp bots** answering automatically.

## The rough consensus

Drawing on the chat's [chat 2026-04-27] thread and the linked
Chabad.org article *Can I Let My AI Agent Run on Shabbat?*
(`chabad.org/library/article_cdo/aid/7288064/jewish/Can-I-Let-My-AI-Agent-Run-on-Shabbat.htm`):

| Scenario | Rough position |
| --- | --- |
| Backend computation only — agent crunches data, nothing visible | Generally OK |
| Agent generates output that lands in your inbox / phone Shabbos | Problematic — *maris ayin*; you're acting on it the moment you see it |
| Agent **sends customer-facing email or text** on Shabbos | Problematic — transacts business in your name |
| Agent **processes donations / payments** on Shabbos | Problematic — *sechar Shabbos* concerns |
| Static website / cached page serves visitors | Generally OK (the work happened pre-Shabbos) |
| Scheduled email send queued before Shabbos, fires on Shabbos | Same as a standing-order send — needs a poseik per use case |

This is **not psak**. It's the working summary of how the group has
been thinking. *"Watch for maris ayin"* is the recurring caution.

## What the group has done in practice

- **Sub-group split.** AIFS Builders has its own Shabbos discussion;
  most Chabad-house operators stick to backend-only or pause-on-Friday.
- **Backend boundaries.** Hecher CRM (Elazor Green) queues agent work
  Friday afternoon; resumes Saturday night.
- **Customer-facing nothing.** No AI-written emails, SMS, or social
  posts scheduled to fire on Shabbos.

## The deeper question

The Chassidic frame (from the *Bina Melachutit* thread,
[chat 2026-02-13]): if AI is *bina* without *chochma* and without
*neshama*, does Shabbos prohibition even apply to it the way it
applies to a *shliach* (in the halachic sense — an agent appointed by
a Jew)? Open question. The chat has not produced a definitive
answer.

## Open questions

- What about **Dispatch / Cowork notifications** that arrive on
  Shabbos but the shliach doesn't read until Saturday night?
- **Cowork spawning sub-tasks** that themselves spawn more tasks.
- **AI as your *shliach* (halachic agent)** — does *zachin l'adam
  she-lo b'fanav* apply?
