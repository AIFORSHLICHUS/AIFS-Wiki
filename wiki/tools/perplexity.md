# Perplexity

AI-powered web search with citations. The group's go-to for **research
that needs sources**, less for nuanced writing.

## What it is

A search-first AI: every answer is grounded in citable web pages.
Subscription tiers:

- **Free** — full chat, limited Pro queries per day.
- **Pro** — $20/mo. Higher limits, more models.
- **Max** — $200/mo. Includes Comet (agentic browser) and other
  premium features.
- **Model Council** — 2026-02 release, lets Perplexity consult multiple
  models per query. [chat 2026-02-06]
- **Spaces** — project-style threads with uploaded documents.

## Free year hacks

## What the chat uses it for

- **Donor and prospect research** — "background info on baalei batim
  and giving potential."
- **Source verification** — when ChatGPT cites something dubious,
  paste it into Perplexity to see real web sources.
- **News &amp; current events** with citations.
- **Comet (agent)** — fills out grant applications, multi-step web
  forms. [chat 2025-08-19]
- **Spaces** — upload PDFs / docs for project-specific Q&amp;A.

## Strengths

- Citations always shown. Easier to verify than other chat AIs.
- Better than ChatGPT for finding *current* information.
- Free tier is actually usable.

## Weaknesses

- "Weaker for nuance" than ChatGPT/Claude. [chat 2025-09-05]
- Even with web search on, still hallucinates occasionally.
- Voice mode "perplexing." [chat 2025-09-11]
- Periodic outages — "spazzing out, gets stuck on 'thinking'."
  [chat 2026-05-01]

## Comet (agentic browser)

[chat 2025-08-19] introduced Comet. Use cases:

- Auto-fill grant applications.
- Multi-page web tasks (find businesses, scrape public info, compose
  emails).
- Form-heavy administrative work.

Requires Max ($200/mo) or invite.
