# Wispr Flow

Voice-to-text *keyboard replacement* with pre-saved templates. The
chat's favorite dictation tool by Q2 2026.

## What it is

`wisprflow.ai` — installs as a system keyboard / hotkey. Speak, get
formatted text in any app. Pre-saved *snippets* expand into longer
templates.

Free tier exists; paid for heavy use.

## How it differs from ChatGPT voice mode

ChatGPT voice = transcribe + chat with model.
Wispr Flow = transcribe + auto-format + paste into *any* app
(WhatsApp, Gmail, Google Docs, your CRM). No model-driven Q&amp;A.

## Strengths

- Side-button activation on phone.
- Fast, accurate formatting.
- Snippets enable repeated workflows.
